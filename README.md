# AI智能任务助手

一个智能任务管理Web应用，帮助你更高效地管理日常任务。

## 功能特点

### 基础功能
- **智能输入解析** - 输入"事儿1 事儿2 事儿3"自动拆分为3个独立任务，支持逗号/顿号/换行分隔
- **任务展示** - 气泡/卡片形式展示任务，显示标题、截止时间、优先级标签
- **分区管理** - 预设分区：今日待办、本周计划、稍后处理、已完成，支持拖拽调整
- **完成操作** - 点击任务标记完成（显示删除线），快捷键删除任务

### 进阶功能
- **时间设置** - 为任务设置截止日期、时间、优先级
- **周期性任务** - 支持每日/每周重复、自定义间隔
- **未完成顺延** - 一键将过期或未完成任务顺延到明天/下周
- **语音输入** - 语音识别输入任务（Web Speech API）
- **每日总结** - 自动生成每日任务log，可导出

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **状态管理**: React Context + useReducer
- **数据存储**: LocalStorage

## 快速开始

### 环境要求

- Node.js >= 18.0.0

### 安装步骤

1. 下载项目文件到本地

2. 安装Node.js环境：
   - Windows: 运行 `node.msi` 或从 https://nodejs.org 下载
   - 项目已内置Node.js: `v:\Poj\assistant\nodejs\node-v20.11.0-win-x64\node.exe`

3. 安装依赖：
   ```bash
   npm install
   ```

4. 启动开发服务器：
   ```bash
   npm run dev
   ```

5. 打开浏览器访问 http://localhost:5173

### 构建生产版本

```bash
npm run build
```

## 使用说明

### 添加任务
在输入框中输入任务内容，按Enter或点击添加按钮：
- 用空格分隔：输入"任务1 任务2 任务3"会创建3个任务
- 用逗号分隔：输入"任务1, 任务2, 任务3"
- 用换行分隔：每行一个任务

### 管理任务
- **移动任务**：拖拽任务卡片到不同分区
- **完成任务**：点击任务卡片标记完成
- **删除任务**：使用删除按钮或快捷键
- **设置时间**：点击任务上的时间图标设置截止日期

### 分区说明
- **今日待办**：需要今天完成的任务
- **本周计划**：本周需要完成的任务
- **稍后处理**：暂时不急的任务
- **已完成**：已完成的任务
